# genvid-explainer machine settings

Copy to `local.md` (git-ignored) and fill in absolute paths. Paths only; never put keys here.

- speko_env: path to a dotenv file defining SPEKO_API_KEY and SPEKO_BASE_URL
- python: interpreter with numpy, soundfile, torch, torchaudio
- music_dir: folder of licensed music tracks (with a LICENSES.md)
- projects_dir: where new video projects are created
- sfx_dir: folder of SFX WAVs named as in template/src/components/Sfx.tsx (copied into template/public/sfx when missing)
